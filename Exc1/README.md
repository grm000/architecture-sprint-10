# Аудит мер безопасности

## Сопоставление процессов с требованиями безопасности

| **Процесс**        | **Требования**                                 | **Соответствие** |
|--------------------|------------------------------------------------|------------------|
| Запись на приём    | Ограничение доступа, шифрование данных.        | Нет              |
| Обработка анализов | Шифрование файлов, разграничение прав доступа. | Нет              |
| Оплата услуг       | Логирование действий, шифрование при передаче. | Частично         |


## Проблемные зоны
1. **Отсутствие разграничения доступа:**
    - Кроме доменной аутентификации, со стороны систем обработки нет ограничений на доступ к данным.
2. **Слабая защита файлов:**
    - Данные хранятся в открытом виде.
    - используются локальные способы хранения данных. В основном это Excel, JPG и PDF
3. **Отсутствует мониторинг и аудит:**
    - Внутренние потоки данных между IT-продуктами никак не контролируются.
    - Результаты работы с данными сохраняются и читаются в файлах и IT-системах без аудита действий
4. **Ручная обработка:**
    - Высокий риск утечек и ошибок, дублирования.

# Тегирования данных

## Теги:

`PII` (персональные данные).

`Sensitive` (чувствительные данные).

`Confidential` (конфиденциальные данные).

`Medical` (медицинская информация).

## Инструментарий

**DataGrail** - позволяет отслеживать путь данных в реальном времени и имеет готовые решения для подключения к PostgreSQL.

# Рекомендации

## Ограничение доступа:

Внедрение ролевой модели (RBAC).
## Шифрование данных:

Transparent Data Encryption (TDE) для базы данных.

Шифрование файлов на уровне хранилища.

## Обезличивание данных:

Удаление идентификаторов для аналитики.

Использование псевдонимизации.

## Настройка системы мониторинга и аудита.

Установка специализированного ПО для отслеживания действий пользователей.

## Повышение уровня автоматизации процессов. Переход к централизованному хранению и обработке данных.

Меры описаны в MVP.
